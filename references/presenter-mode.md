# 幻灯片演讲者模式规范（Presenter Mode）

供幻灯片技能提示词与 `references/layouts.json`、`references/cjk-typography.md` 同级引用，面向生成 HTML 幻灯片的 Agent。

演讲者模式用于双屏或分屏放映场景（演讲者看提词与计时，受众看全屏幻灯片）。生成 HTML 幻灯片时，必须严格遵守以下四大核心规范。

---

## 核心规范

### 1. 稳定标识（`data-slide-id`）
- **规则**：每个 `<section>` 元素必须带有 `data-slide-id="<稳定标识>"` 属性（例如 `data-slide-id="cover"`、`data-slide-id="growth-data"`）。
- **目的**：确保在演讲者模式下双屏翻页、大纲跳转、进度同步与备注联动定位不漂移；不因 DOM 节点重排或顺序调整而错位。
- **命名约束**：
  - 必须在整套幻灯片中全局唯一。
  - 建议与幻灯片文件名或 slide id 保持一致，格式推荐使用 `[a-z0-9_-]+`（如 `intro`、`market-analysis`、`q3-financials`）。

### 2. 备注载体（`<aside data-notes>`）与提词卡要点
- **规则**：演讲者备注统一放置在对应 `<section>` 内部末尾的 `<aside data-notes>` 容器中。
- **提词卡式要点（Cue Cards）**：
  - 必须采用提词卡式要点（Bullet Points / 关键词 / 短语提示），**严禁写成长篇大论或整段逐字朗读稿**。
  - 提词卡包含：核心论点关键词、数据记忆锚点、发问/互动提示及切页过渡提示。
- **容量与约束**：
  - 单页备注精炼控制在 50–200 字之间（遵循 baoyu-design / claude-slides 规范，上限不超过 4,000 字符）。
  - 结构清晰，便于演讲者扫视而不分心。

### 3. 单页时长预算（≤ 90%）
- **规则**：所有单页演讲时长预算之和必须 **≤ 用户总时长的 90%**（预留至少 10% 缓冲时间，应对问答互动、切页动画与临场突发）。
- **时长分配原则**：
  - 用户指定总时长（如 10 分钟 = 600 秒）：总规划演讲时长 ≤ 9 分钟（540 秒）。
  - 各页根据内容深度设定单页时长预算（如封面页 30s、要点页 60s、核心数据页 90s），并在 `<aside data-notes>` 首行明确标注（如 `⏱️ 预算：60s`）。
  - 若用户未指定总时长，默认按单页 60–90 秒基准规划，同样应用 90% 预算上限折算。

### 4. 讲稿备注与页面要点一一对应
- **规则**：`<aside data-notes>` 中的提词点必须与当前页面视觉呈现的核心要点、图表数据或结论**严格一一对应**。
- **对应要求**：
  - **点对点映射**：页面展示 3 条要点，备注提词必须按相同顺序提示对应 3 条展开逻辑与支撑论据。
  - **无冗余与遗漏**：不遗漏页面关键信息，不引入页面无关联的游离内容。
  - **过渡衔接（Transition）**：备注结尾处标明指向下一页的过渡提示语（如 `衔接：引出下一节市场竞争格局`），保证讲演连贯。

## 标准 HTML 结构示例

```html
<!-- 示例：数据页（符合 layouts.json S05 规范及演讲者模式规范） -->
<section id="metrics" data-slide-id="metrics" data-layout="S05" style="...">
  <h2>2026 Q3 核心增长指标</h2>
  <div class="metric-number">320%</div>
  <p class="metric-desc">年度经常性收入同比增幅，创历史新高</p>

  <!-- 演讲者模式备注：提词卡式要点，时长预算 ≤ 90%，与页面要点一一对应 -->
  <aside data-notes>
⏱️ 预算：75s（总时长预算 10min 内）
• 核心数字：强调 320% 是去除汇率波动后的净增长（对应页面大字）
• 支撑论据：主要由新产品线海外拓展驱动（对应同比增幅说明）
• 互动提问：现场询问销售团队各区交付情况
• 过渡衔接：下一步展示驱动增长的客户细分（引出下一页）
  </aside>
</section>
```

## Agent 验收核对表

在输出 HTML 幻灯片代码前，Agent 必须逐页核验以下四项：
- [ ] **每页稳定标识**：每个 `<section>` 是否均带有全局唯一的 `data-slide-id`？
- [ ] **备注载体与格式**：是否使用 `<aside data-notes>`？内容是否为提词卡式要点而非整段稿？
- [ ] **时长预算与缓冲**：单页时长预算标注之和是否 ≤ 用户总时长的 90%？
- [ ] **页面要点对应性**：提词要点是否与页面视觉要点逐项对应，且包含清晰的下一页过渡提示？
